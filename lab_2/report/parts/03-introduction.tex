\ssr{ВВЕДЕНИЕ}

Целью лабораторной работы является выполнение сравнительного анализа алгоритмов умножения матриц по трудоёмкости.

Задачи работы:
\begin{itemize}
    \item описать решаемую задачу согласно варианту;
    \item разработать алгоритмы решения задачи согласно варианту: стандартный алгоритм умножения матриц, алгоритм Винограда и оптимизированный по варианту алгоритм Винограда;
    \item описать разработанные алгоритмы схемами алгоритмов;
    \item описать требования к программному обеспечению;
    \item описать средства реализации алгоритмов;
    \item реализовать разработанные алгоритмы;
    \item выполнить тестирование реализации алгоритмов;
    \item описать модель вычислений для оценки трудоёмкости алгоритмов и выполнить теоретический расчёт трудоёмкости;
    \item описать инструменты замера процессорного времени выполнения реализаций алгоритмов;
    \item выполнить массированные замеры процессорного времени выполнения реализаций алгоритмов умножения матриц в зависимости от линейного размера квадратных матриц, отдельно для чётных и нечётных размеров;
    \item выполнить сравнительный анализ алгоритмов по трудоёмкости и по данным выполненных замеров.
\end{itemize}
