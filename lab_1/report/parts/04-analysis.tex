\chapter{Аналитическая часть}
\section{Постановка задачи}
В данной лабораторной работе решается задача поиска элемента в массиве. Дан массив уникальных целых чисел. Для заданного значения требуется определить, содержится ли искомое значение в массиве, и если содержится --- вернуть его индекс в массиве.

Для решения задачи требуется разработать следующие алгоритмы:
\begin{itemize}
	\item поиск полным перебором;
	\item нерекурсивный бинарный поиск, вариант реализации 1;
	\item нерекурсивный бинарный поиск, вариант реализации 2;
	\item рекурсивный бинарный поиск.
\end{itemize}

\section{Вывод}
В результате аналитической части была поставлена задача поиска элемента в массиве и определены алгоритмы для её решения.
